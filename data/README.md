# 数据说明

`dlut-emotion-ontology.csv` 来自 [yizhanmiao/DLUT-Emotionontology](https://github.com/yizhanmiao/DLUT-Emotionontology)，原始资源由大连理工大学信息检索研究室整理，仅限学术研究使用。商业使用须联系 `irlab@dlut.edu.cn`。

引用：徐琳宏, 林鸿飞, 潘宇, 等. 情感词汇本体的构造[J]. 情报学报, 2008, 27(2): 180-185.

`precision-map.json` 与 `degree-gradients.json` 是本项目的教学增强数据。DLUT 提供情绪类别、强度和极性，不直接等同于同义词库。
