# 转写断句、分段与词语高亮设计

## 目标

录音实时转写、音频上传转写和粘贴文本整理时，统一提供易读的断句、分段和词语突出显示。展示增强不修改原始转写，不影响 ASR、报告生成或历史保存。

## 展示规则

- 按 `。！？!?；;` 等句末标点断句。
- 缺少句末标点的连续文本超过 80 字时，每 80 字仅在显示层拆成一行。
- 每段最多 3 句；已有 2 句且加入下一句会超过 160 字时提前分段。
- 实时 partial 文本与已确认 final 文本使用同一套渲染规则，避免停止录音后版式突变。
- 三类词使用不同颜色和底部强调：
  - 填充词：`嗯、呃、额、啊、呢、那个、就是、就是说`
  - 犹豫词：`可能、也许、大概、应该、我觉得、好像、似乎、或许、不一定、感觉`
  - 笼统词：`想要、觉得、很好、非常、东西、事情、这个`
- 多个规则重叠时优先级为：填充词、犹豫词、笼统词。例如“那个”只计为填充词。
- 转写区上方显示三类词的实时数量；没有命中时显示 0。

## 组件边界

新增独立的纯函数模块，负责：

1. 将文本拆为段落和句子；
2. 按最长词优先匹配三类词；
3. 返回安全、可渲染的结构和分类计数。

渲染层只负责把结构转换成段落与高亮 `span`。所有普通文本必须转义，不能把转写内容直接作为 HTML。

## 数据流

`ASR update / final transcript / pasted text` → `格式化与分类` → `转写区分段渲染 + 计数更新`。

报告保存仍使用原始 `session.transcript`。生成报告按钮、历史记录和 Markdown 导出逻辑不变。

## 错误与边界

- 空文本显示原占位提示，计数归零。
- 无标点长文本按显示长度拆分，不向原文写入虚构标点。
- 英文、数字和未命中词保持原样。
- 高频短词不得在其他词内部误判；按词表最长项优先，重叠位置只标一次。

## 验证

- 单元测试覆盖断句、长句拆分、2–3 句分段、三类计数、重叠优先级和 HTML 转义。
- 渲染测试覆盖实时 update、录音停止、上传完成、粘贴文本四条入口均调用统一渲染。
- 全量测试确保 ASR、手动报告生成、历史保存和报告展示不回归。
