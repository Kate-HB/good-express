# Good Express 质量升级设计

## 1. 目标与优先级

在不破坏现有 Windows 离线能力的前提下，依次解决替词覆盖不足、ASR 错字与重复字、报告模板化、旧音频接口、历史记录缺失和无法发布安装包的问题。

优先级如下：

1. P0：扩大替词覆盖，并提高语境排序质量。
2. P0：保守修复 ASR 重复字和标点，不擅自改变不确定词义。
3. P1：让报告严格使用“证据—影响—修改动作”。
4. P1：用 AudioWorklet 替换 ScriptProcessorNode。
5. P2：增加本地历史记录和隐私控制。
6. P2：生成 Windows 安装包和便携版。

## 2. 替词系统

采用“人工词表保底 + LLM 补充与验证”的混合方式。

### 2.1 本地路径

- 将精准词映射从少量演示词扩充到高频模糊动词、形容词、程度副词和口头表达。
- 每个候选保存语气、强度、正式度、适用目的、正反例和解释。
- 本地排序读取当前句、最近上下文、整段目的、否定词和计划/愿望/观点等线索。
- 最多返回 3 项；语境证据不足时不提示。

### 2.2 LLM 路径

- LLM 可以在本地候选之外补充候选，但必须返回完整结构和修改理由。
- 新候选经过重复、词性、句子可替换性、敏感词和语境一致性校验。
- 低置信度或无法解释的候选被丢弃。
- 1.5 秒超时后直接使用本地结果，不阻塞录音。
- 界面标记建议来源为“本地词库”或“模型补充”。

### 2.3 DLUT 的作用

DLUT 全量词库继续提供情绪类别、强度和极性，不被当作同义词库。它用于：

- 判断候选与原句情绪方向是否冲突。
- 控制替换后情绪强度变化。
- 统计整段表达的情绪词、类别和强度分布。
- 为最终报告提供可追溯的情绪证据。

## 3. ASR 保守纠错

系统同时保留 `rawText` 与 `cleanText`。

- 自动处理相邻重复字、重复短片段、常见口语断句和标点。
- 只有高置信规则才改正文；无法确认的内容保留原文。
- 每项改动记录位置、原文、修正文本、规则和置信度。
- 分析引擎读取 `cleanText`，历史记录同时保存原文和修正文。
- 禁止用 LLM 静默重写字幕。

纠错必须避免破坏“人人、看看、试试”等合理叠词，并区分 ASR 增量结果重复与说话者真实重复。

## 4. 报告升级

本地报告在无 LLM 时完整可用；配置模型后只进行深化，不改变统计事实。

每个结论都使用以下结构：

1. 证据：引用原句或统计数据。
2. 影响：说明听众可能如何理解。
3. 改法：给出具体修改动作和示例。

报告包含总体定位、亮点、不足、逐句改写、精准词表、情绪分析、流畅度数据和唯一一个下次训练任务。相同证据不重复生成多条评价。LLM 输出必须通过结构校验；失败时回退本地报告。

## 5. 音频链路

- 新增独立 AudioWorkletProcessor，在音频线程采集单声道浮点样本。
- Renderer 主线程只负责批量传输，不执行逐样本循环。
- 使用现有重采样模块统一转换为 16 kHz。
- 录音停止时冲刷最后音频和 ASR 终句，避免丢失尾句。
- 保留明确的录音状态机：idle、starting、recording、stopping、error。

若 AudioWorklet 初始化失败，界面显示可操作错误，不静默回退到已废弃的 ScriptProcessorNode。

## 6. 历史记录与隐私

默认只保存文字、纠错记录、建议、统计和报告，不保存音频。

- 历史页按时间倒序展示，可搜索转写内容。
- 支持查看详情、删除单次和清空全部历史。
- 删除操作只作用于 Electron 用户数据目录，并要求界面二次确认。
- 用户显式开启“保存音频”后才写入 WAV，并在设置页显示占用空间。
- API Key 继续只在主进程解密，永不返回 Renderer。

## 7. Windows 发布

- 使用 electron-builder 生成 NSIS 安装包和 portable 便携版。
- Sherpa 模型不打入 Git；首次启动检测缺失时显示下载引导。
- 下载脚本和应用下载器使用固定 URL、文件大小与 SHA-256 校验。
- 安装包内包含应用代码和 DLUT 数据，模型下载到用户数据目录。
- 发布产物包含版本号、架构和校验值。

## 8. 测试与验收

### 自动测试

- 合理叠词保留，ASR 异常重复被清理，原文与修正文可追溯。
- 高频模糊词覆盖显著增加；同词在不同目的下排序不同。
- LLM 新候选只有通过结构与语境校验后才能展示。
- DLUT 情绪方向和强度参与候选验证与报告。
- 报告每项不足都含证据、影响和改法。
- AudioWorklet 消息格式、重采样和停止冲刷正确。
- 历史搜索、删除、清空和音频默认关闭。
- 安装配置能生成 NSIS 和 portable 目标。

### 真人录音验收

使用至少 10 段中文真人录音，覆盖日常分享、观点表达、计划说明、自媒体口播和工作汇报。人工记录：

- 转写中异常重复是否消失。
- 句末到提示出现的延迟，目标不超过 2 秒。
- 每句候选不超过 3 个。
- 首选候选是否能直接替回原句。
- 无网络、无 LLM 时录音、提示和报告是否完整。

## 9. 非目标

- 本轮不训练新的 ASR 或语言模型。
- 不引入人格评价、声纹识别或心理诊断。
- 不保证 macOS、Linux 和移动端发布。
- 不默认保存音频，不上传未经用户选择的数据。
