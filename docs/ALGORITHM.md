# 算法说明

## 1. 为什么 DLUT 不能直接替词

DLUT 记录词语的情感类别、强度和极性。例如它能帮助区分积极、消极和不同强度，但“情绪接近”不等于“语义可互换”。因此系统把它作为分析特征，不把同一情感类别的词全部当成同义词。

## 2. 候选召回

`precision-map.json` 保存可替换关系，并给每个候选标注语气、强度、场景标签和理由。召回只回答“有哪些词可能合适”，此时还不决定最终顺序。

## 3. 语境排序

规则排序读取当前句、最近上下文和推断目的。计划类线索“先、再、步骤”提升“打算”；未来目标线索“考上、成为”提升“希望”；强烈长期诉求提升“渴望”。排序后只保留前三项，并生成替换后的完整句子。

若配置 LLM，它可以重排候选；1.5 秒内没有结果就使用规则排序。这个设计保证反馈及时，也让模型接口可以替换。

## 4. 最终报告

报告只使用转写、统计与已经产生的建议。亮点和不足必须引用原句；训练任务只能有一个，目的是让用户下一次练习有明确重点。
